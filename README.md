# 対人スキル診断

公開URL: https://chikumatateshina.github.io/PersonalityTest/

GitHub Pagesで動く、32問・4択の場面判断テストです。理解の確認、傾聴、寄り添い、自己制御、距離と配慮、関係修復の6軸を表示します。私生活への質問、写真共有、秘密、人前での指摘、集団での参加など、デリカシーと社会性に関わる対応を含みます。

設問と選択肢は並べ替えて表示します。点数は選択肢の独自配点を軸別に正規化した目安であり、実生活での能力を検証した尺度や参加者の順位ではありません。結果にはレーダー図、軸別スコア、対応の特徴と具体的な練習方法を表示します。

旧診断との混同を避けるため共有URLは #social-v1= を使用します。旧形式のURLは診断開始画面になります。

## 公開

main を push し、GitHub Settings → Pages で main / root を選びます。ビルド不要です。

## 将来の集計機能

collect.js と server/apps-script.gs は拡張用に保存しています。COLLECT.enabled は false のままです。送信の質問・平均比較は表示せず、データの送信・集計取得も行いません。再公開時にはバックエンドの設定、受付確認、匿名化の説明、集計仕様をあらためて検証してください。

## 社会常識と総合診断

対人結果の末尾から、knowledge.js の社会常識24問（4分野・各6問）へ任意で進めます。最終結果は全56回答を使用し、対人6軸平均と社会常識正答率を50%ずつ反映します。各分野のバー、対人側と知識側それぞれ2項目の行動案、社会常識全問の正解と解説を表示します。知識テストの再挑戦は学習後の結果となります。

共有URL #combined-v2= は両テストの回答を含み、再読込で総合結果を復元します。未完了の回答は保存しません。設問・採点を変更する際はURLの版を更新してください。送信・平均化は引き続き無効です。

選択肢は対人診断の質問を表示するたびに再シャッフルします。「戻る」で再表示した場合も前回と違う順序となり、選択済みの回答は元の内容に紐づけて保持します。1〜4キーは現在の表示位置に対応します。

社会常識は計算・理科の問題を含めず、情報共有と慎重さ、公共の場のふるまい、仕事と約束、プライバシーと尊重の各6問です。旧 combined-v1 の結果は新版で再採点せず、開始画面に戻ります。

## 共有時の正解表示

総合結果の共有リンク（既存の combined-v2 を含む）から復元した画面では、各問の回答一覧・正解・解説を生成しません。点数・グラフ・行動の目安は表示します。正解と解説はその場で社会常識への回答を完了した直後のみ表示し、再読込でも共有表示に切り替わります。コピーする文章に正解や解説は含みません。URLには従来どおり選択した回答の番号を含みます。これは画面表示の制御であり、静的サイトの採点データ自体を秘匿する機能ではありません。
